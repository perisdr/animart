# Demon Slayer 4K versions

Rain, Steam, and Speed; Fine Wind, Clear Morning; The Japanese Footbridge; The Great Wave off Kanagawa; and The Abbey in the Oakwood were upscaled directly from their non-tinified originals to 3840 × 2160 using System.Drawing high-quality bicubic interpolation. These preserve the original artwork without generative edits; they are not native 4K generations. The Great Wave uses the existing corrected Tanjiro original.

Files follow `Demon Slayer X Painting Title X 1080p.png` and `Demon Slayer X Painting Title X 2160p.png` in `Assets/Demon Slayer/`. Existing optimized 1080p files were renamed to match, and catalogue links updated while keeping stable artwork IDs.

`scripts/tinify_variants.py` creates compressed 2160p PNGs and 640 × 360 WebP thumbnails in `Assets/Demon Slayer/tinified/` using the Tinify API.
